A file server made in python, HTML and CSS with simple to use customization.

first install requirements:
```
pip install -r requirements.txt
```

then run setup-server.py:
```
python setup-server.py
```

and setup your server.

your users will have a Name, and a UUID/Password,
its a random string, if you want to change it to a password, 
edit users.json.

then once your server is setup run main.py:
```
python main.py
```

then you can do 127.0.0.1:[port]

if you want it publicly accessible, you can tunnel or port forward.
